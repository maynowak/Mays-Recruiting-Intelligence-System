no real identity token, no real personal data.**

## Synthetic fixtures

- The PDF is generated by `tools/make_synthetic_canary_pdf.py`: one page,
  Helvetica, only `CANARY APPLICANT`, fictional role/education/skills. No
  e-mail, phone, address, photo, employer or identifier.
- The job ad is a fictional `Canary Systems GmbH` ad with skills only.
- Expected CV extraction: `Python, AWS, Terraform, Docker, Linux, SQL` plus the
  `MSc Computer Science` education line. ATS tags are derived from the job ad.

## Temporary job storage (S3 semantics)

Fake-S3 tests (`S3JobStore`, no AWS call) verify:

- default TTL **2 h**, hard maximum **4 h** (`expires_at` and `max_expires_at`);
- access refused after 2 h and after 4 h (`JobExpired`), cleanup at 4 h;
- `extend` caps at the original 4 h maximum;
- cross-tenant key access is not found (`JobNotFound`; the key includes
  tenant/user), so no cross-tenant read is possible;
- SSE `AES256` and tenant/user/sha256/expiry metadata on every put;
- > 1 MiB rejected (`JobTooLarge`); the S3 lifecycle is only a backup.

## Authenticated test identity (for a later live canary)

The matrix above runs at service level with a synthetic `Identity`. A live
canary needs an existing, non-production test identity; **no Cognito change is
part of CANARY-10A**. Documented claims:

| Claim | Canary value |
|---|---|
| `iss` | existing dev pool issuer (`https://cognito-idp.eu-central-1.amazonaws.com/<dev-pool>`) |
| `client_id` / `aud` | existing dev test app client |
| `custom:tenant_id` | `tenant-canary` (synthetic tenant) |
| `sub` | synthetic canary user id |
| `token_use` | access token for API calls; id token only for user identity |
| entitlements | granted explicitly for the canary only (currently none) |
| consent | `analysis-processing` 1.0 with `consent_notice_approved=true` only in the synthetic harness |

The agent takes tenant/user from the verified WorkItem/runtime context, never
from the request body; `caller_partner_id` is `ris-internal`. A live canary
remains **blocked** until the notice, entitlements and apply are approved.
