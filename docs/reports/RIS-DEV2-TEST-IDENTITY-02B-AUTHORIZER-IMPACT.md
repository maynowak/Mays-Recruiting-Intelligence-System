## 2. Planned impact

### Human authorizer — expected update

The Human authorizer will remain resource ID `9i4w8r` and will change to:

```text
issuer:   https://cognito-idp.eu-central-1.amazonaws.com/<new ris-dev2 pool id>
audience: <new ris-dev2 Human public client id>
```

The concrete pool/client IDs are generated by Cognito and are intentionally not
invented or placed in configuration before apply. The pool name and client name
are deterministic: `ris-dev2-dev-users` and `ris-dev2-dev-client`.

All 64 routes attached to the Human authorizer remain attached to the same
authorizer. This includes:

- Profile and `/me` routes;
- CV creation, retrieval, update, deletion, document and search-profile routes;
- ApplicationV1 create, get, list, patch, status, history, cover-letter,
  export and delete routes;
- privacy inspect/export and erasure routes;
- APIProfile/credential administration routes;
- platform, health, agent and offer routes;
- partner-agent execution routes.

No route authorization type or public route is added.

### M2M authorizer — preserved, no update intended

The M2M authorizer remains resource ID `9eli0a`, with the existing external
issuer/audience pair and the single route:

```text
POST /v1/m2m/agents/{agentId}/execute
```

This preserves the existing machine contract and avoids a destructive
authorizer/route removal. The new managed Cognito pool does not receive an M2M
client or resource server in Human-only mode.

## 3. Token behavior

- Existing external Human tokens will no longer authenticate Human routes after
  the planned in-place Human authorizer update; they will fail issuer/audience
  validation (normally HTTP 401).
- Existing external M2M tokens remain valid for the preserved M2M route until a
  separate authorized change is made.
- New Human tokens must be issued by the new `ris-dev2` pool/client and use the
  configured Authorization Code + PKCE flow.
- No token is created, decoded, logged or stored by this analysis.

1. all existing Human routes still reference the Human authorizer;
