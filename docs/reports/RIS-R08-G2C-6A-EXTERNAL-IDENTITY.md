# RIS-R08-G2C-6A — External Identity

**Status:** IMPLEMENTED / OFFLINE VERIFIED / AWS MUTATION NOT PERFORMED

## Implemented contract

The Terraform root now has an explicit `identity_mode` with values:

- `managed` (default; existing Cognito module behavior);
- `external` (fail-closed references only).

External mode requires a pool ID, pool ARN, complete HTTPS issuer, human app
client ID and M2M app client ID. The variables validate region/account-shaped
ARNs and the issuer/pool relationship. Missing or malformed values fail before
resource planning. There is no fallback to managed mode.

`module.cognito` has `count = 0` in external mode. API Gateway receives the
explicit issuer and audiences from the supplied references. The authorizer
still uses JWT validation for both human and M2M routes; no token or user
contract was weakened. The external domain is informational only and is never
declared as a resource.

## Files

- `terraform/variables.tf` — identity mode and external reference contract.
- `terraform/main.tf` — conditional managed Cognito and API wiring.
- `terraform/modules/api/variables.tf` — complete issuer input.
- `terraform/modules/api/main.tf` — both authorizers use the explicit issuer.
- `terraform/outputs.tf` — safe identity outputs and mode marker.
- `installer/ris.py` — project overlays may carry non-secret external IDs and
  identity mode.
- `tests/test_g2c6_identity_orders_modes.py` — offline protection tests.

No user-pool, app-client, domain, CloudFront, DNS or ACM resource is added for
external mode. No secret or client secret is emitted in outputs or reports.
