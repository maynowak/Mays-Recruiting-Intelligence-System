# Partner Portal Privacy Requirements

## Legal required
- Privacy notice
- Data processing information
- Account deletion request
- Data export request
- Request status tracking
- Contact channel for privacy requests

## Recommended self-service
- Application deletion request
- Credential rotation
- Retention information
- Consent management where applicable
- Backup deletion explanation

## UX improvements
- Request status tracking UI
- Automated email confirmations
- Data export preview

## Transparency
Explain backup retention, deletion windows, and legal retention exceptions in plain language.
